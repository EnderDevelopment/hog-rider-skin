# Minecraft Texture: Hog Rider Pixel Skin

Hog Rider Pixel Skin is a 64x64 Minecraft texture for a Java Edition skin, presented as clean pixel art inspired by the Hog Rider character from Clash of Clans. It features a muscular, tanned barbarian with dark hair, a raised mohawk, thick beard, aggressive facial expression, bare chest, leather details, arm wraps, and dark boots in the classic Java skin layout.

## Install

1. Download or clone this project.
2. Open `assets/textures/hog_rider.svg` in an image editor that supports SVG files.
3. Export the artwork as a 64x64 PNG.
4. Preserve the pixel edges when exporting. Use nearest-neighbor scaling or disable smoothing if your editor provides those options.
5. Open the Minecraft Launcher and start Minecraft: Java Edition.
6. Open the Skins tab and select New Skin.
7. Choose the exported PNG file.
8. Select the Classic or Wide model, then save and equip the skin.

## Use

The SVG uses the standard 64x64 Java Edition skin layout. After exporting it to PNG, equip it from the Minecraft Java Edition Skins menu.

The artwork includes the main head, torso, arms, legs, head overlay, limb overlays, leather belt details, arm wraps, boot tops, beard, mohawk, and dark hair. The design uses crisp pixel edges and high-contrast shading for visibility in-game.
